# 口播写作

需要制作视频时由 [主流程](../video-editing-workflow/SKILL.md) 接续；只写稿不要求先选字体。

1. 确认受众、内容重点、时长意图、语言、说话风格和稿件可改范围。原稿、本人真实反应和用户指定样本优先；没有风格信息时询问，并给短样段供选。参考作者只借表达机制，不搬经历、结论、口头禅或声线。
2. 保护真实动作、顺序、结果、数字、引用和不确定性。当前稿已确认则不重写；局部修改只动指定部分。
3. 按内容组织表达：一个开场给主题和继续看的理由，解释承担新增信息，术语紧跟作用或准确比喻，结尾完成本条因果或判断。聊天、新闻、教程、故事的结构不同，不统一套悬念、收益或互动话术。
4. 问句必须接回答；句子按作用分层，有长短变化，自然连接。删除重复但保留有意义的真实反应。用户删掉开头或主语后，复读下一句，修复悬空的“这里/这个”，不偷偷恢复被删内容。
5. 时长不足时建议减少承诺或内容，不靠机械加速塞满。未有录音只估阅读范围并注明估计；不把字数推成真实时间戳。
6. 自查可说性、证据和说话风格。默认交付一个可录版本；需要时加少量重音/停顿标记，不全篇标满。不虚构实测或观众反馈。

用户明确需要开头诊断、标题或去模板感时，可按安装状态使用 `dbs-hook`、`dbs-content`、`dbs-xhs-title`、`humanizer-zh` 或 `shuorenhua`；它们是可选诊断，不是写稿前必须串联的链路。缺少时说明，仍可完成基本写稿。

没有用户录音时交付可录稿；AI 配音另按用户选择和可用工具执行。稿件确认后制作分镜不再擅改文案。

DBS 的当前上游是 CC BY-NC 4.0，旧 `dbs-hook` / `dbs-xhs-title` 已不在当前目录；商业制作不默认调用，先按能力清单核对许可与新名称。尚未确立来源的旧 `shuorenhua` 不在包内，同名替代需要用户知情选择。
