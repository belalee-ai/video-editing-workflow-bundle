# B-roll 素材导演

先按 [需求确认](../video-editing-workflow/references/intake.md) 读取本项目已锁设置，缺项询问；不携带任何固定真人、IP、服装或颜色资产。

逐个语义节点判断：真实操作/结果要证明就用录屏；数字、流程、分类、对比优先信息动画；本人经历或反应且人物能增加理解时才考虑真人/插图；抽象概念可选物体隐喻。人物模式、视觉风格、制作后端分别选择，不绑定套餐。

每节点交付 `原文或时间点 / 观众需理解什么 / 真实证据或示意 / 是否人物 / 风格 / 完成态 / 后端 / 接回位置`。不需要补画面的部分保留原片。

有人物时锁定本视频的参考来源、身份、服装、发型、饰品、可变动作与禁改项。参考图必须实际查看，注明它负责身份、风格还是编辑目标。未提供本人参考时不能凭空使用作者照片，人物可选无。

使用已确认的素材先查重；确有缺口才制作。新方向先确认画面提案和一个静态完成态，再做短动画；样例通过后扩展。用户只要提示词就停在提示词。图片画幅和视频画幅分别确认，未答不自动使用 1:1 或 3:4。

可选后端：提示词用 `good-broll`；明确半调纸拼贴才选 `gbro-collage-broll` / `gbro-collage-info`；需要精确词级、可编辑层时用 ChatCut 原生 MG 或选定本地动画工具。未安装或不可用则说明，不静默切工具。

拼贴动画要有真实透明分层，或使用已确认的首尾帧生成流程；不能将扁平图粗裁成多边形冒充独立贴纸。不自动改成弹跳、抖动或循环漂浮。每个镜头先定动作与停留职责。

按 [验收规则](../video-editing-workflow/references/editing-qa.md) 查人物一致性、素材比例、原文、遮挡、入场时间、声音与最终文件。按实际状态交付，静帧不证明动画已制作。
