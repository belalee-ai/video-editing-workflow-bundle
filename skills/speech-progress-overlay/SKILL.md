# 语音章节进度条与人物陪伴

本模块合并了原有“章节导航”和“人物陪伴”两种做法，供每位使用者按自己的需求改。没有作者人物、配色、字体或固定平台预设。仅修改用户指定的进度叠层，保留当前工程里的手动调整；不顺手重剪口播、改字幕或导出。

## 先沿用已确认设置，再问缺项

若从主剪辑流程进入，读取当前项目简报；单独使用也可直接工作，不要求重新安装其他通用 Skill。按 [需求与配置](references/customization.md) 分组确认：是否需要章节，是否人物（无/固定/跟随），位置和占比，字体字号与参考、配色底板、线条、动作强度和安全区。视频中的真人与进度条上的角色是两个独立选择。

已确认项直接沿用；没有参考先给少量方案，不静默使用示例参数。没有回复不视为接受。配置保存在使用者自己的项目，后续局部修改只问受影响项，不将个人偏好写进共享包。

## 语义与时间

确认目标工程、唯一音频、实际导入分辨率、画布、fps、总长。按任务或讲述主题的变化提出模块及短标签，让用户确认划分与文案；不能按平均秒数或句数凑段。词级时间来自真实转写或人工校时，不从演示配置推断。

同一个单调进度值驱动底层深色填充、细线和游标：已完成模块宽度之和 + 当前模块宽度 × 本段口播进度。已说完词计满，正在说的词可在真实起止时间内插值，停顿保持；章节标签只渐变颜色，不跳字号、字重或基线。详见 [时间与实现](references/implementation.md)。

## 布局与人物

- 标签与人物是独立开关，共六种组合。无标签时移除文字、分隔线与空白槽；无人物时不留下角色占位。
- 模块宽度由短标签可读性和语义权重决定，也可经用户选择等宽、自定义或按时长；不能擅自机械等分。
- 固定人物可在任意经确认的安全锚点；跟随人物与进度共用控制器，两端按真实可见轮廓夹取，不改变进度本身。
- 人物大小依据透明图的可见边界，不能照搬他人 PNG 外框或关节坐标。未提供/未授权人物时先用无人物方案或等待素材，不自动生成作者角色。
- 单张图只能整体移动。需要呼吸、抬手、摆腿等独立动作时，用使用者自己的分层图和关节绑定；不能把平移说成肢体动作。按语义节点安排动作，不逐帧 AI 重绘或短循环铺满。

## 随包可修改源码

需要验证布局或控制逻辑时使用 `scripts/progress-core.js` 和 `scripts/make-preview.cjs`。它们不联网、不调用 ChatCut，使用 Node.js 内置模块；完整字段与命令见 [配置说明](references/customization.md)。`assets/example-config.json` 是无人物、合成时间的中性演示，不是新项目默认值。将示例复制到使用者项目中修改，不直接覆盖共享模板。

该源码提供确定性的进度/人物位置与浏览器 SVG 预览，**不是 ChatCut 已创建的 MG、透明视频或自动肢体绑定器**。进入 ChatCut 后读取当前官方 MG、转录和验收说明，按实际协议创建可编辑资产与实例，暴露已确认的参数；不能用本地预览替代编辑器回读。不修改共享资产影响其他视频。

## 验收与交付

先给实际画幅的静态布局（包括底片、字幕带和平台控件遮挡），再给覆盖章节切换的短动作测试，确认后接全片。人物有独立动作时，需连续播放 2–5 秒看得见的动作样片；仅有网页首帧或代码通过不能声称已动起来。

检查开头、切换前后、每段中部、末帧：文字可读、不抢先揭晓；填充/线条/游标同步；标签不跳动；人物完整且不挡字幕、脸或证据；进度不回退，终点与唯一音频及工程总长一致。更改音频后重做时间映射。透明输出须在目标剪辑器实际导入检查，普通 MP4 不作透明素材。

交付用户配置、真实模块时间、可编辑工程的资产/实例标识与已检查内容。清楚区分浏览器样张、可播放样片、ChatCut 已验证和待验证；仅在用户已要求导出时输出视频文件。
