# 语音章节进度条

只处理用户要求的进度叠层，不顺手剪口播、改字幕或导出。先读 [主流程](../video-editing-workflow/SKILL.md) 及当前 ChatCut MG、转录与验收说明。

确认目标工程、唯一音频、画布、fps、总长；再确认：是否章节文字，是否人物（无/固定/跟随），人物参考、位置大小、字体、颜色、底板透明度、方圆角和线条样式。全部使用用户设置，没有随包角色或固定配色。空间不足时先确认替代布局。

模块按观众正在理解的任务变化划分，不按句数或平均秒数。记录每段 `短标签 / 起始词 / 起止帧 / 本段词结束帧数组`，真实节点来自词级时间或人工标注。没有有效时间点先转写/校时。

设第 i 段归一宽度为 w_i，总和为 1。当前进度 = 已完成模块宽度之和 + 当前模块宽度 × 已说完词数/本模块总词数；零词段改用人工确认的时间映射。所有已完成状态、底层填充、细线、游标共享一个进度值，单调、不闪回。模块宽度可等宽或按时长，但必须是本项目确认的策略，不从上一条继承。

无人物不保留空角色槽；无标签不保留空文字槽。跟随角色以可见轮廓夹取起终点，不能只保证中心在画布内；固定位置也要避开平台控件、字幕与证据。透明 PNG 的外框不能充当可见人物大小。

在当前 ChatCut 协议下生成可编辑 MG，暴露标签、字体、颜色、图像、可见大小、位置、时长和所选模式。不要修改跨视频共享资产影响别的实例。用户需要独立透明素材时核对透明输出链路，普通 MP4 不能冒充透明。

先给静态布局，再给覆盖一次模块切换的短测试；确认后接全片。检查首帧、切换前后、每段中部、人物边界和末帧；实际播放看进度、文字状态与人物是否同步。报告真实模块时间、工程资产/实例和已检查内容。
