# 时间、人物与编辑器实现

## 唯一时间基准

先读取实际工程和唯一口播音频；原始分辨率、导入后素材、时间线画布和输出规格分别核对。确认实际词级转写与音频一致，更换音频或去停顿后重新校时。模块起点是该讲述任务的真实起始词，不是平均切片。

模块归一宽度为 w_i。当前进度为 `sum(w_before) + w_i * fraction_i`。本实现中，已完成词贡献 1，当前发音词按真实 start/end 贡献 0–1，停顿贡献保持，除以本段词数得到 fraction。它不暗示字/词长度与听感均匀；若项目要求不同进度观感，先给短样确认。末段到终点时统一为 1，段尾无声区可保持已读满状态。

无可靠词时间时先转写/人工标注。无声段可用人工确认的单调时间映射，不把缺数据悄悄降级为平均分段。`progress-core.js` 拒绝模块空洞、重叠、词越界和倒退映射；不会校验输入是否真来自录音，仍需人工/工具回听。

只有一个 `progress/frontX/fillWidth`，深色底板、细线、游标共享该值。章节切换时已完成标签保持完成色，当前标签只做颜色渐变；字号、字重、基线固定。人物到两端被夹取时，不能反向修改填充终点。

## 两个独立开关

| 标签 | 人物 | 结果 |
|---|---|---|
| none | none | 单线进度 |
| chapters | none | 章节导航 |
| none / chapters | fixed | 进度独立前进，人物留在用户确认的位置 |
| none / chapters | follow | 人物跟随同一进度前沿，必要时在两端安全夹取 |

固定位置不限左侧。是否全宽、内收、顶部或底部由本项目决定；没有标签就移除空槽和分隔线。进度条本身始终单调；人物节点反应与惯性不能带着填充回退。

## 可见边界与人物动作

1. 测量使用者图片的原始尺寸和非透明边界，记录相对原图的 x/y/width/height。先确认可见高度，再等比推导宽度；不要直接使用 PNG 外框定大小。
2. 跟随 x = clamp(进度前沿 − 可见宽度/2, 安全区左边, 安全区右边 − 可见宽度)。固定位置同样检查完整轮廓。若动画有转动/摆动，还要检查整个动作的扫过边界。
3. 单张图片仅能平移/整体变换。若希望头、手、腿独立动作，先准备或确认自己的分层素材，为该人物重新标关节、遮罩、重叠接缝与锚点。旧人物的蒙版和关节位置不可套在新形象上。
4. 确认分层完成态后，按真实语义节点做动作短语。固定人物也可有可见动作；跟随人物可叠加节点反应。动作只依赖当前时间、用户素材与节点，不使用随机漂移、逐帧 AI 重绘或短周期反复 yoyo。
5. 想要肢体动作但只有一张图时，说明差距，让用户选择先做静态跟随，还是另行授权制作分层资产；不擅自改形象。先看 2–5 秒手机尺寸可播放测试，再做全片。

## ChatCut 接入

读取使用者当前官方 MG、转录、验收说明，遵守宿主实际支持的组件、字体、图像属性和调用方式。先回读目标时间线和实例，保留用户手改；不复制作者旧工程 ID 或旧工具参数。

- 可复用源码的状态函数，但 DOM/SVG 字符串不是可直接上传的 MG JSX。依当前协议把状态映射成可编辑组件；图片按实际图像属性导入，不放临时私有路径。
- 暴露章节文字/宽度/时间、标签开关、人物模式/图片/尺寸/位置、字体字号字重、颜色/透明度、底板圆角/线宽、渐变时长。根据协议限制必要时拆成相关属性，不能只暴露一个无法编辑的成片视频。
- 创建资产和把实例放到时间线是两步；完成后回读实例属性与真实合成帧。仅返回资产 ID 不等于已显示。
- 共享资产优先实例级覆盖；不能改一个视频时改变其他实例。当前宿主无法表达某种效果时，先说明差距和替代方案，不擅自切换后端。
- 普通 MP4 没有可用于任意叠加的透明通道。用户要求独立透明素材时，实际验证编辑器支持的格式与 alpha/混合链路，再导出并重新导入抽帧。

## 验收定位

静态：实际画布、手机尺寸，检查第一标签、全部字体、人物完整轮廓、字幕带、平台控件、底板透明度及素材证据。

连续：首帧，每个章节切换前后与渐变结束，各段中部，末帧；跟随模式两端均查。检查颜色连续、位置不跳、线/点/填充同步、没有空槽、末段不漂移。原始帧计算通过只能证明逻辑，须查看实际播放与编辑器合成。

回听：对齐真实音频与模块节点；若本次只加叠层，不改动口播。若用户同时要求改音频，完整字头字尾与自然气口优先，切点前后回听完整一句，重建字幕及进度映射。
