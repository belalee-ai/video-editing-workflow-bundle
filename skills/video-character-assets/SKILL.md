# 人物与 IP 素材

按 [需求确认](../video-editing-workflow/references/intake.md) 确认是否需要人物、真人/插图类型、参考来源、画幅、透明要求、动作、位置大小与文字。无参考时先问能否设计虚构人物；不能使用其他人的照片代替本人。

把身份和画风分开：身份参考负责脸、发型、服装、饰品、比例及用户确认的不变量；风格参考只负责线条、材质、配色与留白。先实际看参考图，写清各图用途，同一视频锁定一套造型。服装、手环、性别、头身比没有作者默认值。

先查已有动作，有合适素材直接复用；缺什么才生成什么。新系列先出一张代表图，确认后扩展。每幅只做清楚动作，主体大小依已确认布局，不套用固定百分比。图片编辑只改当前明确问题，保留未涉及区域；透明目标要实际检查 alpha。

用当前宿主支持的图片工具与对应说明，工具不可用时交付方案并说明缺口，不把提示词说成图片。生成后实际查看身份、造型、动作、准确文字、裁切和可读性。与截图同场时人物放界面外，不改按钮、数值或结果冒充实测。

交付实际图片、用途、画幅与状态；静态人物不表示已完成动画或接入工程。
