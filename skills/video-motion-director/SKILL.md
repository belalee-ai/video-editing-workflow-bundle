# 动效选型

按 [主流程](../video-editing-workflow/SKILL.md) 的已确认画幅、字体、风格与布局工作。明确效果直接实现当前范围，不重复开大菜单；没有方向时给少量差异明确的提案，写清可见动作、作用、所需工具和验证方式。推荐不等于用户已选择。

判断主任务：抓注意力、解释关系、突出差异、转换场景或承接对象。先用真实素材，完成态确定后才设计入场、停留、退出；不能依赖运动掩盖布局错误。

- 主剪辑中的短标题、数字、关系和强调：优先 ChatCut 原生可编辑 MG。
- 复用确定文字动作：用 `text-motion-library` 的同源源码，不凭效果名称另写。
- HTML 视频编排与局部素材：选已装 HyperFrames 流程。
- 复杂逻辑、批量或精确帧：按需选 Remotion。
- 对象连续变形：按需选 `onetake`，先核对当前许可和实际画幅。
- 镜头配方与产品运镜：按需选 `video-shotcraft`，读取准确镜头卡、示例与许可。
- 网页界面的弹簧、跟随与空间连续性：按需参考 `apple-design` 或相关 GSAP Skill，不改变整条视频风格。

每镜只选一个主制作路线。工具可用性、费用与输出格式检查后再执行；不因目录里有 Skill 就承诺能渲染。

新方向先交一个实际样例，查看真实完成态、中文英文间距、人物与字幕避让、手机可读性。连续运动还要实际播放。样例确认后扩展；用户只要预览不自动导出。套用第三方示例前用本项目参数覆盖，冲突不能隐去。
