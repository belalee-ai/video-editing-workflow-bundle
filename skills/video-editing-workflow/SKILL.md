# 视频剪辑工作流

这是制作流程与工具调度 Skill，需要实际剪辑工具才能执行视频制作。主编辑器为 ChatCut；不附账号、额度、模型服务或任何作者的个人风格。

## 先确定本次做到哪里

从用户当前要求、已确认简报、原稿、素材或指定工程中识别平台、受众、要讲清的一件事、材料和交付终点。已有确认稿不重写，已有工程不重建。只写稿、审片、生成提示词或局部修改时，做到所需阶段，不启动整套制作。

先读 [需求与视觉确认](references/intake.md)。**新视频进入素材生成或创意剪辑前，适用的说话风格、画幅、人物有无及位置、素材大小、字体风格及大小参考、字幕、素材风格和声音必须已确认。** 没有真人、字幕、配乐或生成素材，也要明确记录为“无/不适用”，不能靠留空推断。

- 已在本项目明确的信息直接回读沿用，不重复问。材料能证明尺寸，不能替用户决定审美偏好。
- 缺项时分组问最关键的问题，给少量选项和推荐；推荐写“建议”，等用户选择或明确授权采用后再锁定。未回复不等于接受。
- 用户说“你来推荐/自由发挥”只覆盖明确委托的范围；把将采用的方案和参数写清。未委托的必选项仍需补齐。
- 可以先盘点素材、读工程、查事实、整理待选方案；方向未锁定时不付费生成、不批量制作、不渲染整片。
- 已有视频的局部修正只确认受影响项，不为改一个字要求填全表。

将结果记入用户当前项目的简报，可用 [简报模板](templates/brief.md)；个人配置留在用户自己的项目，不写回共享 Skill，不自动上传或带入下一位用户。

## 阶段与能力

| 当前阶段 | 工作与交付 |
|---|---|
| 选题/资料 | 核实事实与证据，明确受众和本条承诺；时效信息查原始来源 |
| 草稿/口播 | 用本人的原稿和已选说话风格组织表达；调用组合包中的口播能力，不默认模仿任何作者 |
| 待录音 | 交付可录稿；未授权不改成 AI 配音，不猜词级时间 |
| 已有音频/粗剪 | 确认唯一音频；转写校正，去重复与停顿，保留完整字词和自然气口 |
| 布局/分镜 | 锁定完成态与位置尺寸；有人像或复杂构图先展示实际画幅静态样张 |
| 素材/动效 | 真实证据优先；按语义节点进场，先做一个样例，经确认后扩展 |
| 工程/审片 | 在指定 ChatCut 母版中保留可编辑轨道、字幕与动效；按实际画面和声音验收 |
| 导出 | 用户已明确要求对应文件时输出；剪辑请求默认交付工程与预览，发布需另有授权 |

分镜最少记录：`时间窗 / 对应口播词 / 画面作用 / 关键词 / 素材来源 / 入场顺序 / 完成与退出 / 声音 / 接回位置`。无唯一音频或真实时间点时只交语义分镜，标注待校时。

## 工具接入

进入 ChatCut 时读 [ChatCut 接入](references/chatcut.md)。按任务读取用户当前安装的官方插件说明，不复制旧插件目录、版本路径或不可用的工具名。

用户要求进度条、章节导航或人物跟随进度时，调用随包 [speech-progress-overlay](../speech-progress-overlay/SKILL.md)，沿用本项目设置并仅补问缺项；不套用作者人物/配色。

关联能力及安装状态见 [组合包能力路由](references/toolbox.md)。只加载当前需要的 Skill。实际缺少插件、脚本、模型或权限时，说明缺口并给可行选择；不能把清单、提示词或文件安装说成已能出片。其他后端只在用户选择或同意切换后使用。

## 制作与交付底线

读 [剪辑与验收规则](references/editing-qa.md)。以下原则不因子 Skill 默认值而改变：

- 真实界面、操作与结果用真实素材；重建要标示意。
- 唯一音频驱动字幕、动效、音效、进度和总时长；禁止吞字。
- 完成态先确认，再决定进场；关键对象不早于讲述出现。
- 主画面放关键词，完整句子放字幕；同屏重点通常不超过五项。
- 画面比例与人物布局按本项目已确认值；素材不拉伸，标注跟随目标同步运动。
- 回读工程并看真实合成帧；最终 MP4 另查开头、切换、复杂画面、后半段与结尾，回听音频切口。
- 授权与状态分开：已规划、已写入工程、已生成预览、已导出、听感待确认、已发布。未实际完成的检查如实说明。

局部改动后更新受影响的简报、时间点和验收结果，不新增无关效果，不把本次参数固化为他人的默认。
