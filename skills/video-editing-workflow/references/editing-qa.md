# 剪辑与验收规则

## 时间与声音

确认一条实际使用的口播音频，所有字幕、动效、音效、章节和工程总长从它出发。未锁音频只做语义分镜。词级触发优先真实词级时间；只有整句时间戳时人工标关键点，不能按平均语速伪造。

重复试讲优先选完整、顺畅的一版，只有确有缺口才拼接。切点依据波形与回听，保留字头、尾音、连读和必要呼吸；不能只按 SRT 裁切。只换画面时保持已确认原声。变速、去停顿、重排后同步字幕、图层、音效、章节与总长。

底噪、回响、音量、速度分开诊断；先在同一语义段比较响度接近的处理前后样本，再决定整段处理。背景音乐、素材原声、旁白各自判断职责，不能一律静音需要展示的现场声或盲目保留冲突的原配乐。人声清楚、音量稳定，检查片段增益与轨道压低量的共同作用。

每次改音频及最终导出后，回听受影响切口前后至少一句完整话。无法实际听音时把“听感”列待用户确认；能解码、波形正常、ASR 一致均不能替代听觉验收。

## 分镜与素材

先明确每镜要让观众理解的关系和完成态；标题、数字、对象跟随对应语义分时进入。主画面只放关键词、数字与关系，完整句子留在字幕。数值与单位完整，揭示不能短暂显示会造成误解的另一个数。

操作与结果用真实录屏，不能用假界面充当实测证据。静图需有清楚观看焦点，可用裁切、推近、遮罩揭示或标注帮助理解；观众确需读取证据时允许稳定停留。界面运动时框、箭头、标注与目标放同一运动容器同步；不能跟随就不用定位线。

真实素材保持原宽高比。仅放大能在最终尺寸读清且承载结论的内容；正文放大后仍不可读，就保持素材并使用外部短标签。主素材和讲解文字分区，避开已有字幕带；不重复叠同一句大卡。

人物、素材、字幕与平台 UI 的安全区按已确认布局检查。不能拿固定左上/右下角覆盖所有镜头；人像按每镜空位放置，调整后回看。数字安全区参考必须标其来源/画布，不能冒充平台现行规定。

## 可编辑工程与输出

一条母版管理原始轨道、字幕、素材与动效；拆分片段从母版范围输出，避免把整条压缩文件导回再剪。ChatCut 任务不能用本地扁平合成视频替代可编辑时间线。

原始文件、导入素材、画布与导出规格逐项核对。导入时发生降采样，以实际进入工程的尺寸配置，不把放大当提高画质；具体限制看当前导入器，不固化旧版本上限。帧率、比例与透明要求按真实能力验证。

调试先看静态完成态和短预览，确认后再做整片。局部修正只重做受影响模块；使用固定当前文件名，覆盖用户资料前按其授权处理，原片不删除。没有授权不清理历史文件或移动源素材。

## 实际检查

1. 工程回读：指定项目/时间线正确，素材已就绪，无意外空隙、重叠、错位或旧实例；字幕、图层和时长一致。
2. 真正查看合成帧：开头、进出场、完成态、复杂构图、真人/录屏交界、后半段和结尾。按手机尺寸检查字形、大小、比例、遮挡、安全区和加载。
3. 连续预览：节奏、字幕同步、声音、转场与动作是否流畅；静图不能证明节奏。
4. 只有最终文件已获授权输出时，检查真实 MP4 的尺寸、帧率、时长、音轨、关键帧与切口，不能用 HTML 快照代替最终文件验收。
5. 报告实际已做检查和待确认项；项目预览、文件已导出、本人终审和外部发布分别记录。

检查力度与改动匹配；已确认主体结构、信息与风格不因“去模板感”自动重做。
