# 需求与视觉确认

## 怎样问

先提取已知设置，为每个字段记录 `用户明确 / 已确认简报 / 工程测得 / 建议待确认 / 不适用`。参考图能帮助提案，但不能自动代表用户同意所有字体、构图与颜色。不要把“建议”记成“已确认”。

每轮优先问一组会改变结果的问题，给清楚推荐；可用宿主的提问卡片，上传文件则使用实际文件入口。用户不懂术语时解释成可见差别，先让其选方向，再把选择转成实际参数供核对。允许“没有参考，请给方案”，随后先确认方案。

## 生成前需要锁定的内容

| 类别 | 需要确认/测量什么 | 可以怎样问 |
|---|---|---|
| 目标与交付 | 平台、受众、核心结果、时长范围、已有材料、语言、此次终点、输出位置 | 这次给谁看，做到稿件、可编辑工程还是视频文件？ |
| 说话风格 | 本人原声/旁白/无人声，聊天感/解释/新闻/故事等方向，语气强度、信息密度、保留口头反应，原稿是否可改 | 希望像聊天分享还是清楚解释？有自己的样片或稿件可参考吗？ |
| 声音来源 | 唯一口播音频、语言/口音、是否保留现场原声；若选 AI 配音，需确认声音与工具 | 用已有真人录音、后补录音还是已授权的 AI 配音？ |
| 视频画幅 | 明确 W:H、像素宽高与帧率；不要只根据平台猜竖屏 | 9:16、16:9、1:1，还是按你提供的样片？ |
| 真人/人物 | 有无真人；底片/画中画/透明抠像/插图角色；是否为用户本人，所用参考与允许的变化 | 是否露脸？全屏、圆形小窗、矩形小窗还是透明人物？ |
| 人物位置与尺寸 | 默认锚点、可否逐镜换位、可见轮廓占比、裁切范围与脸部焦点 | 人像想放哪里、多大？有没有不能遮住的操作或字幕？ |
| 主素材布局 | 录屏/图片/素材窗口宽高与位置、真人同屏关系、主次层级、留白/底板、完整展示或允许裁切 | 素材铺满还是放在窗口里？要看完整界面还是只看重点区域？ |
| 画面内容占比 | 真人主导、录屏主导、信息动画、补充素材的使用范围；仅需要时确认时长占比 | 希望大部分时间看真人，还是看操作与素材？不必硬填百分比 |
| 字体与字号 | 主标题/副标题/字幕/强调字分别选字族、中文与英文数字、字重、字号或相对尺寸、颜色、行数、间距、描边/底板 | 字体和大小有参考吗？没有的话，先给两种真实字体排版样张供选 |
| 字幕 | 有无、单/双语、逐字/短句、位置与最大行数、是否保留底片已有字幕、遮挡区域 | 保留原字幕还是新做？放哪里？是否需要双语？ |
| 素材风格 | 真实录屏/摄影/手绘/纸拼贴/3D/信息动效等；配色、背景、材质、参考、禁用项 | 想用哪类素材？有参考作品吗？哪些风格不要？ |
| 动效与节奏 | 平稳或活泼、重点动作、镜头停留、转场、是否启用进度条/章节/文字动效 | 需要解释关系、抓注意力还是安静陪衬？哪些效果必须保留？ |
| 音乐与音效 | 不要/自带/现有曲库/另找，氛围、音色、强弱、现场声处理、用途许可 | 要配乐吗？偏轻、推进感或其他方向？先听短样再定 |
| 权限与依赖 | 可用文件及用途，云端处理范围、已装工具、允许的生成方式和费用上限、素材使用条件 | 是否允许把这些素材导入所选云端工具？有付费生成预算吗？ |
| 规格与审片 | 实际源文件、导入后素材、画布和输出四项规格；安全区、审片人、文件格式/透明要求 | 先给布局样张和工程预览，还是已明确要求最终视频？ |

说话风格影响写稿和剪辑保留方式，不能靠倍速伪造；未提供录音时不填实际语速。风格混合比例只有用户需要时再讨论，不把“自然/专业”等词编造成可测百分比。

## 将“占比”和“放哪里”变成可复查参数

这些量分开记录：

- 画幅：宽:高，例如 9:16，不代表素材窗口也必须同一比例。
- 人物/素材空间占比：分别记录 `x/W, y/H, width/W, height/H`；这些是边界框比例，不等于面积比例。圆形人像记录直径/W；透明人物以可见轮廓计算。
- 素材原始比例：保持原比例；`contain` 是完整展示，`cover` 是允许裁切。选择裁切时记录焦点，不能默认裁去证据。
- 内容时长占比：按互斥的主画面类别计时可合计为 100%；画中画是独立叠层，同屏不能重复计入主画面总和。不为凑比例插无关素材。
- 字号：在实际画布上记录像素值与相对高度。参考图的 60px 不能直接复制到不同分辨率；必须查看真实字形、字重、换行和手机预览。
- 位置：静态默认锚点与逐镜允许变动分开写；每镜仍避开字幕、脸、主证据和平台控件。

## 字体不是只填一个名字

核对字体是否在实际编辑器/渲染后端可用、字重是否存在、中文/英文/数字是否缺字以及用户用途是否允许。分享包不携带字体文件。缺失或许可不明时给替代样张并询问，不能静默换字体后仍宣称一致。用户选定“由 AI 推荐”时先出样张，记录最终选择。

不把任何作者的青柠绿、粉色、固定斜角、字幕底板、圆形人物、单行字幕或固定字号设为全体默认。

## 哪些步骤可以继续

| 信息状态 | 可以继续 | 需要等什么 |
|---|---|---|
| 只有主题，风格不明 | 核实资料、列素材与缺项、给少量方案 | 用户确认适用需求，再制作 |
| 只要求写稿 | 确认受众、事实与说话风格后写稿 | 不因缺字体阻塞文字任务；未来制作前再补视觉 |
| 已有录音与确认风格 | 读取素材、转写校正、提切点建议 | 改语义、删核心内容或缺失布局仍需确认 |
| 要生成素材但没有视觉定案 | 文本方案、草图说明、提出样张参数 | 必选项及样张生成范围确认后，先做一个样张 |
| 定版图已确认 | 做当前样例动画，按真实音频校时 | 用户要求先看图时不能提前渲染整段 |
| 只修现有字幕错字 | 读取当前实例并改指定字 | 沿用其余设置，不重问整套需求 |
| 子 Skill 有未确认默认 | 保持本项目已确认设置，检查适配 | 无法覆盖或冲突时说明并询问，不静默套用 |
