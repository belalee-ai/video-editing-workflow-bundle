# ChatCut 主剪辑路线

## 必要条件

宿主能调用当前 ChatCut 连接器/插件，用户有自己的登录与目标项目访问权。仅安装本 Skill 不会安装插件、生成账号、提供额度或获得项目权限。工具缺失时可继续整理需求与分镜，不能声称已经写入工程。

执行前读取当前安装的官方基础说明，再按任务读素材导入、口播剪辑、转录、Motion Graphic、验收、导出等说明。工具名与参数以当前工具 schema 为准；Hosted/Desktop 不能互当同一环境。没有对应工具时不给虚构安装命令或后台地址。

## 新项目与已有工程

按照当前插件说明建立或指定用户要求的项目，显示工具返回的编辑器入口。不能因名称像就改到旧工程。已知目标项目时用其真实标识，读取相关时间线、素材和实例；用户可能手动修改过，编辑前刷新相关范围。不要一次并行读取相互依赖的发现步骤。

选择用 ChatCut 处理素材不等于授权额外付费生成。导入云端文件前按本次已确认的素材与处理范围执行；权限拒绝时停在该步骤，不绕过限制。

## 在工程中剪

- 从原始素材创建可编辑片段、字幕、音轨和叠层；口播选择/去重复按当前官方语音剪辑流程执行。
- 声音结构先锁，再做依赖它的字幕、B-roll、音乐与进度；有转录修改时按插件要求在完整编辑阶段后刷新字幕。
- 生成式视频与本地动效仅作为明确用途的单个补充片段，接入原母版；不把整支剪辑在本地压成一个 MP4 再冒充多轨工程。
- Motion Graphic 用当前官方实现方式；字体、配色、文字、大小、位置和时长按本项目设置暴露为可编辑属性。资产创建与放置分开检查，现有共享资产的局部变动优先实例覆盖，避免影响其他片段。
- 文字动效载荷生成器输出的是代码与属性数据；按当前插件协议内联提交，不能把本地 JSON 路径当已上传或已接入。

## 核对与交付

核对四项分辨率与真实帧率，按当前插件导入结果配置母版；不把某次旧导入上限写成永久事实。读取修改后的实例、时间与实际合成帧，必要时播放检查。

普通剪辑交付工程与预览。已明确要求 MP4/下载/最终交付时按当前导出流程执行，不反复询问同一授权；单纯改剪辑、看预览不推导成导出请求。外部发布单独授权。

交付标明工程入口、改动范围、已检查内容，以及是否真正导出。工具不可用时说明所停阶段与缺口，其他后端需用户选择后再接入。
